Esta es la misma aplicación que vas a construir con React, escrita con las herramientas de los cinco ejemplos anteriores y nada más. Úsala, léela entera (app.js son ~150 líneas) y quédate con la sensación: cada cambio de datos exige que tú vayas a repintar el DOM a mano. Ese es el problema que React elimina.

    No hay tareas que coincidan.

    Ahora compara. Abre frontend/src/paginas/Tareas.jsx y frontend/src/componentes/TaskCard.jsx: hacen lo mismo que esta página, pero sin una sola llamada a createElement, appendChild o innerHTML. Tú cambias el estado; React repinta.
