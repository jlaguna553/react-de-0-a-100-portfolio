1. Texto y jerarquía

Un subtítulo (h3), hijo lógico del h2 de arriba

Un párrafo. El navegador colapsa todos los espacios y saltos de línea consecutivos en uno solo, así que el formato del código fuente no afecta al resultado.

Dentro de un párrafo puedes marcar importancia (strong), énfasis (em), código en línea (code), letra pequeña (small) y texto resaltado (mark).

Un salto de línea forzado se escribe con br:
esta frase quedó en la segunda línea.

Una cita larga va en blockquote. El navegador la indenta por defecto. 
Un bloque <pre> SÍ respeta
   los espacios
       y los saltos de línea.
Por eso se usa para mostrar código.

  1. Primer paso

  3. Tercer paso

Lista de definiciones (dl)

HTML
Define la estructura y el significado del contenido.
CSS
Define la presentación: colores, tamaños, posiciones.
JavaScript
Define el comportamiento: qué pasa cuando el usuario interactúa.

Por qué esto importa para React: cuando en React escribas {tareas.map(...)} vas a estar generando exactamente estos <li> desde un array de datos.

7. Errores comunes de principiante

  1. "Divitis": envolver todo en <div> cuando existía <nav>, <section>, <button>...
  2. Usar <div onclick> en vez de <button>: el div no recibe foco con Tab ni responde a Enter. Un botón sí.
  3. Olvidar alt en las imágenes.
  4. Inputs sin <label>.
  5. Saltarse niveles de heading por razones visuales.
  6. Anidar mal: <p><div></div></p> es inválido (un p solo admite contenido en línea).
  7. Repetir un id: los id son únicos en toda la página; para agrupar usa class.
